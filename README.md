# BIA 2027

manuel officiel BIA d'eduscol (5 chapitres, 65 sections).

Checklist cochable en 3 phases :

1. **Lecture 1 — comprendre** (sept. 2026 → 10 févr. 2027) : lire les 65 sections, 1 mini-fiche par section.
2. **Lecture 2 — mémoriser** (16 févr. → 12 avr. 2027) : relecture + fiches + QCM par chapitre.
3. **Annales — s'entraîner** (13 avr. → jour J) : sujets complets chronométrés, points faibles.

Page unique `index.html`, HTML/CSS/JS pur, sans build. Progression enregistrée en `localStorage`.
Thème clair/sombre. Marque d'une étoile ★ les sections difficiles → liste des points faibles.
